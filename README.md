# 🤖 AI Chatbot Assistant & Dashboard
> **Smart AI Assistant Interface with Code Highlighting, History & Dark Mode**

A feature-rich, modern AI Chatbot web application designed with a sleek glassmorphism dashboard UI. Offers real-time conversational interface, code syntax highlighting, chat history persistence, theme customization, and responsive layout.

## ✨ Highlights & Features

- 💬 **Interactive AI Chat:** Instant, natural language response engine with simulated typing indicator.
- 💻 **Syntax Code Highlighting:** Integrated Highlight.js for clean code block formatting (JavaScript, Python, HTML, CSS, SQL, C++).
- 💾 **Persistent Chat History:** Save and resume conversation sessions locally using browser LocalStorage.
- 🌓 **Dark / Light Glassmorphism Theme:** Smooth theme switching with glassmorphism backdrop blur effects.
- ⚡ **Quick Prompts & Commands:** Pre-configured prompt suggestions for fast interaction.
- 📋 **Copy to Clipboard:** One-click copy for AI code snippets and response text.
- 📱 **Fully Responsive Layout:** Collapsible sidebar and optimized UI for mobile, tablet, and desktop views.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (Flexbox & CSS Grid, Custom Properties)
- **Code Syntax Highlighting:** Highlight.js v11.9.0
- **Icons & Fonts:** Font Awesome 6.4 & Google Inter Font
- **State Management:** Vanilla JavaScript (ES6+), LocalStorage API

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imaazkhan-web/ai-chatbot-dashboard.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd ai-chatbot-dashboard
   ```

3. **Open in browser:**
   Open `index.html` directly in any web browser.
